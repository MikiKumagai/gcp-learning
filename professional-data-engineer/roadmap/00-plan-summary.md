# Google Cloud Professional Data Engineer 学習計画

## 1. 試験概要

* 試験時間：2時間
* 出題形式：選択式・複数選択式

## 2. 学習ロードマップ

| 順序 | 試験領域               | 出題割合の目安 | 主な学習内容                                            |
| -- | ------------------ | ------: | ------------------------------------------------- |
| 1  | データ処理システムの設計       |     22% | アーキテクチャ、セキュリティ、信頼性、データ移行                          |
| 2  | データの取り込みと処理        |     25% | バッチ・ストリーミング、Dataflow、Pub/Sub、Dataproc、オーケストレーション  |
| 3  | データの保存             |     20% | BigQuery、Cloud Storage、各種データベース、データモデリング、データガバナンス |
| 4  | 分析のためのデータ準備と利用     |     15% | SQL、BI、BigQuery ML、AI/ML向けデータ準備、データ共有             |
| 5  | データ処理ワークロードの運用・自動化 |     18% | 監視、障害対応、コスト最適化、リソース管理、CI/CD                       |

※割合は公式試験ガイドに基づく目安。最新の出題範囲は公式ガイドを参照する。

## 3. 学習記録の管理

| ディレクトリ          | 記録する内容               |
| --------------- | -------------------- |
| `topics/`       | 技術の仕組み、特徴、サービス間の使い分け |
| `labs/`         | SQL・コードなどによる動作検証     |
| `architecture/` | 要件に応じた構成図と設計案        |
| `review/`       | 間違えた問題、判断に迷った点、復習事項  |
