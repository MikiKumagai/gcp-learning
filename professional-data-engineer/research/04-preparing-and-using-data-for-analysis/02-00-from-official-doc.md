## 4.2 AIと機械学習
### Gemini Enterprise Agent Platform とは
- インフラ管理をクラウド事業者がすべて自動・代行するサービス形態（フルマネージドプラットフォーム）
- 機械学習と生成AIモデルを開発する基盤
- Vertex AI の後継とのこと

| サービス | 主な特徴と機能 |
| --- | --- |
| Model Garden | GeminiやClaudeなどの200以上のAIモデルを利用できる |
| Vertex AI Studio | コード不要のクラウド環境。プロンプトの作成やモデルのチューニング |
| Custom ML Platform / MLOps | データ活用の一連のライフサイクルを統一管理 |
| Google Cloud連携 | GCPサービスとの連携、大規模データを活用した高精度なAI・機械学習開発 |

### Gemini Enterprise Agent Platform での ML の概要
MLを大規模に行うための包括的なツールスイートを提供する。様々な場面でMLライフサイクル全体を運用化
- AutoML（自動化された機械学習）を使用して高品質のモデルを迅速に作成
- TensorFlow や PyTorch などの一般的なフレームワークを使用してカスタムモデルを作成

### データの準備
マネージド データセットが用意されているので、モデルトレーニング用のデータ準備が簡単。
イメージ データや表形式データなど様々。
AutoMLではこれが必須、カスタムトレーニングでは任意

### モデルのトレーニング
大規模なモデルトレーニングの運用を支援するマネージド トレーニング サービスが用意されている
インフラストラクチャで、あらゆる MLフレームワークに基づくトレーニング アプリケーションを実行できます。
完成したAIエージェントを社員が利用する環境で、MLの一般的なフレームワークの統合サポートも提供

#### サーバーレス トレーニング
| メリット | 説明 |
| --- | --- |
| フルマネージド コンピューティング インフラストラクチャ | サーバー不要でモデルをトレーニングできる |
| 高パフォーマンス | パフォーマンスを向上させることができる最適化されたトレーニング ジョブ |
| 分散トレーニング | 時間と費用を 削減するためのマルチノード分散トレーニングのサポート |
| ハイパーパラメータの最適化 | モデルの最適な値を自動的に検出する |

### Model Registry によるモデル管理
モデルのトレーニングが完了したら、 で管理できます。
Model Registry は、ML モデルのライフサイクルを管理できる中央リポジトリです。
モデルのバージョンの追跡、モデルの品質の評価、推論の提供のためのモデルのデプロイを行うことができます。
